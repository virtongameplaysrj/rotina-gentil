# 🌱 Rotina Gentil

Agenda gentil para tarefas da casa e lazer, pensada para adultos com TDAH e autismo.
Tudo fica salvo no próprio aparelho, e nada é enviado para a internet.

## 📲 Baixar no Android

- **Pelo Obtainium (recomendado, atualiza sozinho):** adicione o endereço
  `https://github.com/virtongameplaysrj/rotina-gentil`
- **APK direto:** baixe o arquivo `.apk` da versão mais nova em
  [Releases](https://github.com/virtongameplaysrj/rotina-gentil/releases/latest)

## 💻 Outras formas de usar

Veja o passo a passo completo em [COMO-TESTAR.md](COMO-TESTAR.md): abrir no PC, instalar como app
pelo Chrome e configurar a publicação do APK.
